# What is Active Directory

Imagine a big office building with 500 rooms. Without any systems, each rooms has it's own key and it's own lock. Employee Arthur needs access to 10 rooms, so someone has to go to each of those 10 doors and set it up. When Arthur leaves the company, someone has to visit all 10 doors again. It’s a mess.  

Now imagine a **security desk** at the entrance with one central register. It lists every employee, which rooms they can enter, and their ID card details. Every door asks the security desk: “Is this person allowed in?” **That security desk is Active Directory (AD)**.  

In a real company, the “rooms” are computers, file folders, printers and applications. The “employees” are user accounts. AD is a Microsoft service that keeps one central database of all of them. Companies use Active Directory because:

- We log in once with one username and password, and it works on every company computer.
- IT creates, changes or removes our access in one place, not on 500 separate PCs.
